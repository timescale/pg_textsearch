# pg_durable 0.2.8 Release Adoption Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace #478's temporary pg_durable source-commit build with the
checksummed PostgreSQL 17 package published in pg_durable v0.2.8.

**Architecture:** The coverage job downloads and verifies the released Debian
package, extracts it without system installation, and passes the extracted
tree to the existing live integration test. The Rust toolchain, source build,
and source-package cache are removed.

**Tech Stack:** GitHub Actions, Bash, curl, sha256sum, dpkg-deb, PostgreSQL 17,
pg_durable 0.2.8

## Global Constraints

- Use release asset `pg-durable-postgresql-17_0.2.8-1_amd64.deb`.
- Verify SHA-256 `927b091e57be42c63079fc50a548af5f491b223534eaca112c5d1f18299dc29f`.
- Keep `PG_DURABLE_VERSION=0.2.8` as the integration-test version contract.
- Do not install the Debian package into the runner.
- Remove the temporary commit pin, cargo-pgrx setup, source build, and cache.
- Preserve the existing `make test-durable` invocation and coverage behavior.

- [ ] **Step 1: Rehearse the released package locally**

```bash
tmpdir=$(mktemp -d)
curl -fL --retry 3 \
  -o "$tmpdir/pg-durable-postgresql-17_0.2.8-1_amd64.deb" \
  https://github.com/microsoft/pg_durable/releases/download/v0.2.8/pg-durable-postgresql-17_0.2.8-1_amd64.deb
echo "927b091e57be42c63079fc50a548af5f491b223534eaca112c5d1f18299dc29f  $tmpdir/pg-durable-postgresql-17_0.2.8-1_amd64.deb" |
  sha256sum -c -
dpkg-deb -x "$tmpdir/pg-durable-postgresql-17_0.2.8-1_amd64.deb" \
  "$tmpdir/package"
```

Expected: checksum reports `OK`, and the extracted tree contains exactly one
`pg_durable.so`, one `pg_durable.control`, and one
`pg_durable--0.2.8.sql`.

- [ ] **Step 3: Replace the temporary source build**

Keep the coverage-job environment:

```yaml
PG_DURABLE_VERSION: 0.2.8
PG_DURABLE_PACKAGE: pg-durable-postgresql-17_0.2.8-1_amd64.deb
PG_DURABLE_SHA256: 927b091e57be42c63079fc50a548af5f491b223534eaca112c5d1f18299dc29f
```

Replace the cache and source-build steps with:

```yaml
- name: Download pg_durable release package
  run: |
    curl -fL --retry 3 \
      -o "$PG_DURABLE_PACKAGE" \
      "https://github.com/microsoft/pg_durable/releases/download/v${PG_DURABLE_VERSION}/${PG_DURABLE_PACKAGE}"
    echo "${PG_DURABLE_SHA256}  ${PG_DURABLE_PACKAGE}" | sha256sum -c -
    mkdir pg_durable_package
    dpkg-deb -x "$PG_DURABLE_PACKAGE" pg_durable_package
```

Set the existing test step to:

```bash
export PG_DURABLE_PACKAGE_DIR="$PWD/pg_durable_package"
```
