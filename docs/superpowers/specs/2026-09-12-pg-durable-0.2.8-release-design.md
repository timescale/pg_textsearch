# pg_durable 0.2.8 Release Adoption

**Status:** Approved

## Goal

Replace #478's temporary build from an unreleased pg_durable commit with the
published PostgreSQL 17 package from pg_durable v0.2.8.

## Design

The coverage job will download
`pg-durable-postgresql-17_0.2.8-1_amd64.deb` from the v0.2.8 GitHub release,
verify SHA-256
`927b091e57be42c63079fc50a548af5f491b223534eaca112c5d1f18299dc29f`,
and extract it into the workflow workspace with `dpkg-deb`.

The existing `durable_compaction.sh` test will receive the extracted directory
through `PG_DURABLE_PACKAGE_DIR`. Its recursive package discovery will locate
the released library, control file, and version SQL without installing the
Debian package into the runner.

The source checkout, cargo-pgrx installation, Rust build, and source-package
cache will be removed. `PG_DURABLE_VERSION` remains the test's version
contract.

## Failure Handling

The workflow fails before testing if the download fails, the release asset
does not match the pinned checksum, or the extracted package lacks the
artifacts required by `durable_compaction.sh`.

## Verification

Run the live managed-compaction integration locally against an extracted copy
of the released package. Then run #478's GitHub CI and propagate the updated
base into stacked #489.
